## Goal

深度マップを大きく表示し、距離による濃淡を読み取りやすくする。
TFT の画素単位の階調で深度を表示する。
測距値や姿勢判定の精度向上は、本変更の完了条件に含めない。

### 配置と濃淡

- MUST: 左上を原点 `(0,0)` とする。
- MUST: `x=0..127, y=0..127` に深度マップを表示する。
- MUST: セル `[row][col]` を `(col×16, row×16)` に配置する。
- MUST: セルの全 16×16px を使用する。
- MUST: ULD の配列順序を維持する。
- MUST: データの補間、平滑化、回転、反転を加えない。
- MUST: 有効条件を `target_status=5`、距離 0〜4000mm とする。
- MUST: 距離を固定範囲の 64 階調へ変換する。
- MUST: 階調値を `((4000-distance_mm)×63+2000)/4000` とする。
- MUST: 整数除算を使い、中間値は明るい側へ丸める。
- MUST: RGB666 の各成分に同じ階調値を設定する。
- MUST: 0mm を白、4000mm を黒にする。
- MUST: 空間ディザリングとフレームごとの自動正規化を使わない。
- MUST: 無効セルを黒地に赤い対角線 2 本の `×` で表示する。
- MUST: 表示変換で観測値と送信内容を変更しない。

### 文字と状態

- MUST: `x=0..127, y=128..159` を文字表示に使う。
- MUST: 1 文字を 8×16px とする。
- MUST: 各行を最大 16 文字とし、黒地に白で表示する。
- MUST: 1 行目は次の状態を表示する。
- MUST: 2 行目は固定の凡例 `0-4m NEAR=WHITE` を表示する。
- MUST: 状態の変化時は前の文字とマップを更新する。

| 条件 | 1 行目 | マップ |
| --- | --- | --- |
| 最新フレームに有効セルがある | `DEPTH` | 有効セルの濃淡と無効セルの `×` |
| 最新フレームの全セルが無効 | `NO VALID` | 全セルの `×` |
| 起動後に未取得 | `NO DATA` | 黒で消去 |
| 最後の取得成功から 5 秒超 | `STALE` | 黒で消去 |
| 深度の取得エラー | `ERROR` | 黒で消去 |

- MUST: エラー、未取得、更新停止、最新フレームの順で状態を判定する。
- MUST: ちょうど 5 秒の経過では `STALE` にしない。
- MUST: 新しい正常フレームで現在のマップと状態へ復帰する。

### 配線とハードウェア境界

端子構成から 4 線式 SPI と推定する。
SCL / SDA を深度センサーの I²C へ並列接続しない。
下表は Freenove 公式ピン配置と実装に対応する接続とする。
専用資料がないため、以下の条件を初期接続の仮定とする。
初期接続の仮定を購入モジュールの保証仕様として扱わない。

| TFT 端子 | 接続 | 条件 |
| --- | --- | --- |
| GND | GND | Freenove と共通にする |
| VCC | 3V3 | 3.3V 電源で初期確認する。5V を印加しない |
| SCL | GPIO1 | SPI SCLK とする |
| SDA | GPIO2 | SPI MOSI とする |
| RES | GPIO42 | リセット専用とする |
| DC | GPIO41 | コマンドとデータを選択する |
| CS | GPIO38 | SPI CS とする |
| BL | 3V3 から 330Ω の直列抵抗を介して接続 | LED の正極または High 有効入力と仮定する |

- MUST: 信号は ESP32-S3 の 3.3V ロジックを使用する。
- MUST: BL を GPIO から直接給電できると仮定しない。
- MUST: BL の初期接続では外付けの電流制限抵抗を省略しない。
- MUST: BL の電流と点灯状態を実機で確認する。
- MUST: 暗い場合も、根拠なく BL の抵抗を短絡しない。
- MUST: GPIO38 を使用する構成では microSD を併用しない。
- MUST: GPIO2 に接続された基板上 LED への影響を明記する。
- MUST: カメラ、PSRAM、USB、深度センサーの GPIO を維持する。
- MUST: 深度の I2C1、GPIO14 / GPIO21、`0x29` を維持する。
- MUST: 省略可能な深度 INT の GPIO47 を変更しない。
- MUST: 表示は SPI2_HOST の書込み専用デバイスとする。
- MUST: ESP-IDF 6.0.3 の標準 SPI/GPIO API を使用する。
- MUST: 汎用 ST7735 のリセット、sleep out、画素形式設定を行う。
- MUST: 初期化ではコントローラ資料の待機時間を守る。
- MUST: SPI mode 0、8MHz を初期設定とする。
- MUST: 論理列 0〜127 を RAM 列 2〜129 へ書き込む。
- MUST: 行オフセットは 0 とする。
- MUST: 表示オフセット、反転、RGB 順序を実機で確認する。

ST7735S 資料は SPI と RGB666 の技術的な根拠とする。
同資料だけでは購入した ST7735 モジュールの条件を保証しない。
パネル固有の設定は、実機表示を確認して調整する。
複数パネル向けの選択設定や自動判別は追加しない。

### 更新と失敗処理

- MUST: 1 秒周期で最新の深度スナップショットを表示する。
- MUST: 表示のために再測距しない。
- MUST: 更新停止の判定に単調時計を使う。
- MUST: 描画と SPI 転送中に共有観測の mutex を保持しない。
- MUST: 取得・送信タスクを表示タスクより先に確保する。
- MUST: 表示の初期化・転送・メモリ確保の失敗を記録する。
- MUST: 表示失敗時も観測の取得・送信を継続する。
- MUST: 失敗から 5 秒以上空けて再初期化する。
- MUST: SPI のキュー待ちと完了待ちに有限の期限を設ける。
- MUST: 転送中のバッファを解放、上書き、再利用しない。
- MUST: 転送失敗時に未完了の転送へ再試行を重ねない。
- MUST: 描画用バッファを既存の 4096-byte タスクスタックへ載せない。
- SHOULD: 分割転送で必要な描画用 RAM を抑える。
- MUST: SPI の送信成功だけでパネルの接続成功と判定しない。
